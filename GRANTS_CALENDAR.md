# TJF Grants Calendar

The tracked, in-repo version of TJF's grants pipeline — versioned, linkable, and updated directly through GitHub rather than a spreadsheet passed around by email.

## How to Use

1. This tracker lists real, current funding opportunities relevant to Uganda/East Africa across TJF's four pillars, plus two open rows to add new ones.
2. Update the **Status** column as an opportunity progresses: `Not started` → `Researching` → `In progress` → `Submitted` → `Awarded` / `Declined`.
3. Assign an **Owner** (staff/board member responsible) for each opportunity once work begins.
4. Re-check each funder's website every quarter — deadlines and open calls shift. This list reflects information available as of **July 2026** (animal-health rows and the USAID correction added September 2026).
5. For rolling/no-deadline funders (e.g. Segal Family Foundation), treat them as always-open — prioritize based on capacity to write a strong proposal.
6. Found a new opportunity? Don't edit this file directly — open an issue using the **[💰 Grant / Funding Lead](../../issues/new?template=grant_lead.md)** template instead, so it gets reviewed and logged consistently.

**Suggested cadence:** review this tracker in a 30-minute meeting on the first Monday of every month.
