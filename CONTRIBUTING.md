# Contributing to The Jopetnah Foundation

Thanks for your interest in Jopetnah. This repo is our public working space while we build out the Foundation — we welcome input from future board members, volunteers, donors, and partner organizations.

## Ways to Get Involved

| I want to... | How |
|---|---|
| Suggest a change to a program, copy, or plan | Open an [issue](../../issues) describing the change and why |
| Propose a new funding lead for the grants calendar | Open an issue with the funder name, focus area, and link — or submit a pull request adding a row to `docs/GRANTS_CALENDAR.md` |
| Offer skills (design, legal, finance, grant-writing, translation) | Open an issue tagged `offer-of-support`, or email us (see [README](README.md#-get-involved)) |
| Join as a founding board member or advisor | Reach out directly — see [Get Involved](README.md#-get-involved) in the README |
| Report an error or outdated figure | Open an issue tagged `correction` |

## Submitting Changes

1. Fork this repository
2. Create a branch (`git checkout -b update/grants-calendar`)
3. Make your change — keep edits focused and specific
4. Open a pull request describing what changed and why
5. A Jopetnah team member will review and merge

For small fixes (typos, broken links), feel free to open a pull request directly without an issue first.

## Style Notes

- Keep language plain, warm, and specific — avoid jargon and vague claims
- Cite a real source when adding a funder, statistic, or partnership claim
- Mark clearly-illustrative figures (e.g. draft giving tiers) as such until confirmed by the board/finance
- Match the tone of existing docs: direct, human, and free of overclaiming

## Code of Conduct

Be respectful and constructive. This project exists to help real communities — keep discussion focused on how to do that well. Disagreement is welcome; disrespect isn't.

## Questions?

Open an issue, or reach out via the contact details in the [README](README.md#-get-involved).
