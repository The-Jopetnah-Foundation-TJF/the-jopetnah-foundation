# Indicator Reference Guide

## Executive Summary

The Jopetnah Foundation (TJF) uses standardized indicators to measure programme performance, outcomes and long-term impact across all areas of intervention.

This Guide provides a reference library of indicators that support project planning, implementation, monitoring, evaluation and reporting. Programme teams should adapt indicators to the specific context while maintaining consistency in definitions and measurement methods.

---

# 1. Purpose

This Guide aims to:

- Standardize programme indicators.
- Improve data quality.
- Promote consistency across projects.
- Support donor reporting.
- Facilitate evidence-based decision-making.

---

# 2. Indicator Categories

Indicators are grouped into four levels:

| Level | Purpose |
|---|---|
| Input | Resources invested |
| Output | Products and services delivered |
| Outcome | Short- to medium-term changes |
| Impact | Long-term sustainable change |

---

# 3. Indicator Definition Template

Each indicator should include:

| Field | Description |
|---|---|
| Indicator Name | Official indicator title |
| Definition | What the indicator measures |
| Level | Input, Output, Outcome or Impact |
| Unit of Measure | Number, Percentage, Ratio, Currency, etc. |
| Baseline | Starting value |
| Target | Expected value |
| Data Source | Where information comes from |
| Collection Frequency | Monthly, Quarterly, Annually |
| Responsible Person | Staff responsible |
| Means of Verification | Evidence supporting reported results |

# 5. Education Indicators

### Output Indicators

- Number of learners enrolled.
- Number of teachers trained.
- Number of schools supported.
- Number of scholarships awarded.
- Number of learning materials distributed.

### Outcome Indicators

- Percentage improvement in learning outcomes.
- School attendance rate.
- School completion rate.
- Student retention rate.

### Impact Indicators

- Increased literacy levels.
- Improved educational attainment.
- Increased transition to higher education.

# 13. Data Quality Standards

All indicators should be:

- Specific.
- Measurable.
- Achievable.
- Relevant.
- Time-bound (SMART).

Additionally, data should be:

- Accurate.
- Complete.
- Consistent.
- Timely.
- Verifiable.

---

# 14. Indicator Review

Indicators should be reviewed:

- During programme design.
- Before implementation.
- During quarterly reviews.
- During evaluations.
- When strategic priorities change.

---

# 15. Version Control

Changes to indicator definitions should be documented, including:

- Date of revision.
- Description of change.
- Approval authority.
- Reason for update.

---

# Conclusion

Standardized indicators enable TJF to measure progress consistently, compare results across programmes and communicate impact with confidence.

By using this Guide, programme teams strengthen accountability, improve learning and enhance the Foundation's ability to demonstrate measurable results to communities, partners and donors.

---

> **Consistent indicators create credible evidence, and credible evidence drives meaningful impact.**
