# Baseline & Endline Assessment Tool

## Executive Summary

The Jopetnah Foundation (TJF) uses baseline and endline assessments to measure programme performance, outcomes and long-term impact.

A baseline assessment establishes the initial situation before implementation begins, while an endline assessment measures the same indicators after programme completion. Comparing both provides evidence of change attributable to the intervention.

---

# 1. Purpose

This Tool aims to:

- Establish pre-project conditions.
- Measure change over time.
- Support programme planning.
- Demonstrate impact.
- Strengthen accountability.
- Improve future programme design.

---

# 2. Definitions

## Baseline Assessment

A study conducted before programme implementation to establish benchmark values for agreed indicators.

### Objectives

- Understand community conditions.
- Establish indicator baselines.
- Identify priority needs.
- Inform programme planning.

---

## Endline Assessment

A study conducted near or after programme completion to measure achievements against baseline values and project targets.

### Objectives

- Measure progress.
- Assess outcomes.
- Evaluate effectiveness.
- Document lessons learned.

---

# 10. Data Analysis

Compare:

- Baseline values.
- Endline values.
- Planned targets.

Assess:

- Magnitude of change.
- Statistical significance (where appropriate).
- Practical significance.
- Contributing factors.

---

# 11. Data Quality Controls

Ensure:

- Enumerator training completed.
- Tools pre-tested.
- Spot checks conducted.
- Data verified.
- Missing values reviewed.
- Outliers investigated.

---

# 12. Ethical Standards

All assessments should:

- Obtain informed consent.
- Respect confidentiality.
- Protect vulnerable participants.
- Minimize harm.
- Comply with applicable data protection requirements.

# Conclusion

Baseline and endline assessments provide the evidence needed to demonstrate whether TJF programmes have achieved meaningful and measurable change.

By applying consistent methodologies and high-quality data practices, TJF strengthens accountability, learning and impact.
