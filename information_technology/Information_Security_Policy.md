# Information Security Policy

## Executive Summary

Information is one of The Jopetnah Foundation's (TJF) most valuable assets. Protecting information is essential to maintaining trust with communities, donors, partners, employees, regulators and stakeholders.

This Information Security Policy establishes the principles, controls and responsibilities required to protect TJF's information assets from unauthorized access, disclosure, alteration, destruction or disruption.

The Policy supports TJF's commitment to confidentiality, integrity, availability and responsible information management.

---

# 1. Purpose

This Policy aims to:

- Protect TJF information assets.
- Prevent unauthorized access and misuse.
- Reduce cybersecurity risks.
- Promote secure technology practices.
- Establish user responsibilities.
- Support compliance with applicable data protection requirements.
- Strengthen organizational resilience.

---

# 2. Scope

This Policy applies to:

- Board members.
- Employees.
- Volunteers.
- Consultants.
- Interns.
- Contractors.
- Third-party service providers.

It applies to all information systems and assets including:

- Computers.
- Mobile devices.
- Servers.
- Cloud platforms.
- Email systems.
- Databases.
- Applications.
- Networks.
- Physical documents.
- Digital records.

---

# 3. Information Security Principles

TJF follows three fundamental information security principles:

## Confidentiality

Information must only be accessed by authorized individuals.

---

## Integrity

Information must remain accurate, complete and protected from unauthorized modification.

---

## Availability

Information and systems must be accessible when required for legitimate operations.

---

# 4. Information Security Governance

## Executive Director

Responsible for:

- Overall accountability for information security.
- Approving major security initiatives.
- Ensuring adequate resources.

---

## Information Technology Department

Responsible for:

- Implementing security controls.
- Managing ICT security systems.
- Monitoring threats.
- Supporting users.
- Responding to security incidents.

---

## Department Heads

Responsible for:

- Protecting departmental information.
- Ensuring staff compliance.
- Reporting security concerns.

---

## All Users

Responsible for:

- Protecting TJF information.
- Following security policies.
- Reporting suspected incidents.
- Maintaining confidentiality.

---

# 5. Information Classification

Information should be classified according to sensitivity.

## Public Information

Information approved for external sharing.

Examples:

- Public reports.
- Published materials.
- Website content.

---

## Internal Information

Information intended for TJF operations.

Examples:

- Internal procedures.
- Administrative communications.

---

## Confidential Information

Information requiring restricted access.

Examples:

- Financial information.
- Partnership agreements.
- Employee records.

---

## Highly Confidential Information

Information requiring the highest protection.

Examples:

- Beneficiary personal information.
- Sensitive investigation records.
- Security credentials.

---

# 6. Access Control

Access to TJF systems shall follow the principle of:

## Least Privilege

Users receive only the access necessary to perform their responsibilities.

---

Access controls include:

- Individual user accounts.
- Strong authentication.
- Role-based permissions.
- Periodic access reviews.
- Immediate removal of access when no longer required.

---

# 7. Password Management

Users must:

- Create strong passwords.
- Keep passwords confidential.
- Avoid password sharing.
- Change passwords when compromise is suspected.
- Use multi-factor authentication where available.

Passwords must not be stored insecurely.

---

# 8. Multi-Factor Authentication (MFA)

TJF should implement MFA for:

- Email accounts.
- Cloud systems.
- Administrative accounts.
- Systems containing sensitive information.

---

# 9. Device Security

Users must:

- Protect TJF devices from theft.
- Install approved security updates.
- Use security software where provided.
- Avoid unauthorized software installations.
- Report lost or stolen devices immediately.

---

# 10. Email and Communication Security

Users should:

- Verify suspicious emails.
- Avoid opening unknown attachments.
- Protect confidential information.
- Use official communication channels.

Users must report suspected phishing attempts.

---

# 11. Data Protection

TJF shall protect personal and sensitive information through:

- Appropriate access controls.
- Secure storage.
- Responsible sharing.
- Data minimization.
- Secure disposal.

Personal information must only be processed for legitimate purposes.

---

# 12. Encryption

Encryption should be used where appropriate to protect:

- Sensitive files.
- Portable devices.
- Data transfers.
- Backup systems.

---

# 13. Remote Work Security

Users working remotely must:

- Secure their workspace.
- Protect devices.
- Use approved systems.
- Avoid unsecured networks when handling sensitive information.
- Maintain confidentiality.

---

# 14. Software Management

Users must:

- Use authorized software only.
- Avoid pirated applications.
- Apply updates promptly.
- Report software vulnerabilities.

---

# 15. Network Security

TJF shall implement appropriate controls including:

- Secure network configurations.
- Firewall protection.
- Monitoring.
- Access restrictions.
- Secure wireless networks.

---

# 16. Backup and Recovery

Critical information shall be protected through:

- Regular backups.
- Secure storage.
- Recovery testing.
- Documented restoration procedures.

---

# 17. Security Awareness

TJF shall promote cybersecurity awareness through:

- Staff training.
- Security updates.
- Phishing awareness.
- Good practice guidance.

All users share responsibility for information security.

---

# 18. Incident Reporting

Users must immediately report:

- Unauthorized access.
- Lost devices.
- Malware infections.
- Data breaches.
- Suspicious activity.
- Accidental information disclosure.

Incidents should be managed according to the Cybersecurity Incident Response Plan.

---

# 19. Third-Party Security

External providers accessing TJF information must:

- Maintain appropriate security controls.
- Protect confidential information.
- Follow contractual security requirements.
- Report security incidents affecting TJF.

---

# 20. Compliance and Monitoring

TJF may conduct:

- Security reviews.
- Access audits.
- Compliance checks.
- Vulnerability assessments.

Failure to comply with this Policy may result in disciplinary action or termination of access.

---

# 21. Policy Review

This Policy shall be reviewed:

- Every two years.
- After significant security incidents.
- Following major technology changes.
- When legal requirements change.

---

# Conclusion

Information security is a shared responsibility across The Jopetnah Foundation.

By protecting information assets through strong governance, responsible user behaviour and effective technical controls, TJF strengthens trust, safeguards stakeholders and ensures continuity of its mission.

---

> **Protecting information means protecting the people, communities and partners who depend on us.**
