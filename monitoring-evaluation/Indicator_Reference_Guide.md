# Indicator Reference Guide

## Executive Summary

The Indicator Reference Guide establishes standardized definitions, methodologies and reporting requirements for institutional performance indicators used by The Jopetnah Foundation (TJF).

Its purpose is to ensure that programme performance is measured consistently across all projects, departments and partnerships, enabling reliable reporting, informed decision-making and continuous organizational learning.

This Guide serves as the Foundation's institutional indicator registry and should be used when designing projects, developing proposals, monitoring implementation and reporting results.

---

# Purpose

This Guide aims to:

- Standardize indicator definitions.
- Promote consistency across programmes.
- Improve data quality.
- Strengthen donor reporting.
- Support evidence-based decision-making.
- Reduce ambiguity in measurement.
- Facilitate organizational learning.

---

# Guiding Principles

All indicators used by the Foundation should be:

- **Relevant** to strategic objectives.
- **Clearly defined** and unambiguous.
- **Measurable** using reliable methods.
- **Comparable** over time.
- **Practical** to collect and verify.
- **Ethically collected**, respecting privacy and safeguarding requirements.

---

# Indicator Classification

Indicators are grouped into four levels.

| Level | Purpose | Example |
|--------|---------|---------|
| Input | Resources invested | Amount of funding received |
| Output | Immediate products or services | Number of people trained |
| Outcome | Changes resulting from outputs | Percentage of trainees applying new skills |
| Impact | Long-term change | Reduction in household poverty rate |

---

# Standard Indicator Reference Sheet

Every institutional indicator should include the following information.

| Field | Description |
|-------|-------------|
| Indicator Code | Unique identifier |
| Indicator Name | Official title |
| Strategic Outcome | Related strategic outcome |
| Indicator Level | Input / Output / Outcome / Impact |
| Definition | Clear description of what is measured |
| Unit of Measure | Number, percentage, ratio, currency, etc. |
| Baseline | Starting value |
| Target | Expected value |
| Data Source | Where the data comes from |
| Collection Method | Survey, register, observation, etc. |
| Reporting Frequency | Monthly, quarterly, annually |
| Responsible Officer | Role responsible for reporting |
| Means of Verification | Evidence supporting reported values |
| Disaggregation | Gender, age, disability, location, etc. |

# Disaggregation Standards

Where appropriate, indicators should be disaggregated by:

- Sex
- Age group
- Disability status
- Geographic location
- Programme area
- Beneficiary category
- Vulnerability status

Additional disaggregation may be required by specific donor agreements.

---

# Target Setting

Targets should be:

- Evidence-based.
- Realistic.
- Time-bound.
- Consistent with available resources.
- Reviewed annually.

Targets should not be adjusted without documented justification and approval.

---

# Data Verification

Indicator values should be supported by verifiable evidence, including:

- Registers
- Attendance sheets
- Surveys
- Observation checklists
- Financial records
- Evaluation reports
- Digital systems
- Approved databases

The Foundation's Data Quality Assurance Framework provides additional guidance.

---

# Indicator Review

Indicators should be reviewed annually to assess:

- Continued relevance.
- Ease of collection.
- Data quality.
- Reporting burden.
- Alignment with strategic priorities.

Indicators that no longer support decision-making should be revised or retired through the Foundation's governance process.

---

# Version Control

The MEAL function shall maintain the master version of this Guide.

Changes to indicator definitions, formulas or reporting requirements should be documented through version control to preserve consistency over time.

---

# Review

This Guide shall be reviewed annually and updated whenever strategic priorities, donor requirements or organizational practices change.
