# Indicator Reference Guide

## Executive Summary

The Jopetnah Foundation (TJF) uses indicators to measure progress, assess performance and demonstrate impact across its programmes.

A standardized indicator system ensures consistency, reliability and comparability of information across different sectors, projects and geographical locations.

This Indicator Reference Guide provides TJF teams and partners with a common framework for defining, measuring and reporting programme indicators.

---

# 1. Purpose

This Guide aims to:

- Standardize programme indicators.
- Improve data quality.
- Support evidence-based decision-making.
- Strengthen reporting consistency.
- Enable organizational learning.

---

# 2. Scope

This Guide applies to:

- All TJF programmes.
- Projects.
- Monitoring systems.
- Evaluations.
- Partner reporting.

It guides:

- Programme teams.
- MEAL officers.
- Field teams.
- Partners.

---

# 3. Definition of an Indicator

An indicator is a measurable value used to track progress, performance or change resulting from an activity or intervention.

Indicators help answer:

- What has changed?
- How much change occurred?
- Who benefited?
- When did change happen?

---

# 4. Types of Indicators

## Input Indicators

Measure resources invested.

Examples:

- Funding provided.
- Staff assigned.
- Materials purchased.

---

## Activity Indicators

Measure actions completed.

Examples:

- Number of trainings conducted.
- Number of community meetings held.

---

## Output Indicators

Measure immediate results.

Examples:

- Number of people trained.
- Number of services delivered.

---

## Outcome Indicators

Measure changes resulting from activities.

Examples:

- Improved skills.
- Increased access to services.

---

## Impact Indicators

Measure long-term transformation.

Examples:

- Improved livelihoods.
- Reduced vulnerability.
- Increased resilience.

---

# 5. Indicator Selection Principles

Indicators should be:

## Specific

Clearly defined.

---

## Measurable

Possible to collect and analyse.

---

## Achievable

Realistic within available resources.

---

## Relevant

Connected to programme objectives.

---

## Time-Bound

Measured within a defined period.

# 7. Indicator Metadata Requirements

Each indicator should include:

| Element | Description |
|---|---|
| Indicator Name | Official title |
| Definition | Meaning and scope |
| Purpose | Why it is measured |
| Data Source | Where information comes from |
| Collection Method | How data is gathered |
| Frequency | Measurement schedule |
| Responsible Person | Data owner |

---

# 8. Indicator Tracking System

Programmes should maintain:

- Baseline value.
- Target value.
- Current achievement.
- Progress percentage.
- Evidence source.
- Reporting period.

---

# 9. Data Collection Methods

Indicators may be measured through:

- Surveys.
- Registration records.
- Attendance sheets.
- Interviews.
- Assessments.
- Observation.
- Administrative records.

---

# 10. Indicator Quality Assurance

TJF shall verify indicators through:

- Data reviews.
- Field verification.
- Documentation checks.
- Database validation.

---

# 11. Indicator Disaggregation

- Gender.
- Age group.
- Location.
- Vulnerability status.
- Other relevant categories.
